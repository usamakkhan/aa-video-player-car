# AA Video Player Car

Independent Android rebuild in progress, based on analysis of the supplied AA CarPlay Video APKs. The new package is `app.aavideoplayercar`.

Start with [the handoff](HANDOFF.md), [feature status](HANDOFF-FEATURES.md), [build and verification notes](HANDOFF-VERIFY.md), and [the Android project](rebuild/README.md).

The repository contains source, handoff documentation and selected analysis evidence. Original APKs and bulk recovered output remain outside Git. The rebuild has not yet been compiled or verified on a device.
