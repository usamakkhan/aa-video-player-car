Analysis date: 2026-10-11 (user timezone)

SCOPE AND CONCLUSION
====================
This is AA CarPlay Video, package com.aacarplayvideo.app, versionName 1.2, versionCode 202. It is a native Android media dashboard with a separately bundled FreeTube web application. The artifacts contain Android Auto integration; they do not demonstrate Apple CarPlay protocol support.

This report covers all four supplied APKs, their recovered resources, all four DEX containers, native library symbols, disassembly and decompiler output, web bundle structure, major app flows, persistence, network contracts, billing/licensing and external module boundaries. Static code proves implementation is present; it does not prove a feature succeeds on a particular head unit or remote service.

Recovery is extensive but is not a claim of complete original-source recovery or full behavioral equivalence. Original Kotlin source names, comments, build configuration and server implementations are absent. The follow-up pass recovered instruction-level FALLBACK output for all 53 classes flagged by the original decompiler, including the three previously unresolved app-related classes; these outputs are not buildable original Java. Downloadable VLC/TTS code remains absent and is retained as traced components at the user's request. The phone was locked during the recorded UI capture and disconnected during the follow-up, so screen interaction and playback remain unverified.

PREVIOUSLY DIFFICULT METHODS
============================
uw.g(sq, continuation): coroutine that selects an IPTV dashboard recommendation. It reads up to 20 watch-progress entries and returns the first existing non-live channel with the continue-watching label. Otherwise it queries VOD for the active playlist, randomly chooses an item with rating at least 7 and a nonblank poster, falls back to any VOD with a poster, then any series with a poster, or returns null. Malformed rating text is treated as zero. lb0.I performs random list selection. Sources: fallback-complete/defpackage/uw.java, method g; raw Smali call/branch evidence in difficult-method-evidence.json.

This is media-session compatibility behavior, not an additional licensing or network feature. Source: fallback-complete/defpackage/pu1.java, method F.

bt.invokeSuspend: R8 merged coroutine dispatcher, not one coherent feature. The discriminator dispatches 11 branches covering deferred helpers and UI/data operations including Radio Garden search, podcast results, channel/EPG panels, playlist/recycler updates, favorites, music and loading UI. The full instruction listing and direct call/string/branch indexes are recovered. Its merged register types and coroutine continuations must not be read as ordinary compilable Java. Sources: fallback-complete/defpackage/bt.java and difficult-method-evidence.json.

LICENSING, PURCHASES AND SERVER CONTRACTS
=========================================
There are three relevant layers: Pairip's Play license wrapper, Google Play Billing lifetime purchase handling, and publisher license/trial validation.

Google Play product: lifetime_license, type inapp. h92/g92/xp handle querying purchases, acknowledging purchases and an encrypted owned cache. Local entitlement checks consult that cache. This is a recovered client-side policy, not a verification of the publisher's backend purchase accounting.

Publisher API contracts inferred from call sites:
POST https://aacarplayvideo.com/api/license.php
JSON request: license_key (trimmed/uppercased), device_id (Android ID), device_name (manufacturer/model), api_secret.
JSON response: valid, revoked, message, expires_at (optional).

POST https://aacarplayvideo.com/api/trial.php
JSON request: device_id, device_name, api_secret.
JSON response: trial_active, remaining_hours, remaining_minutes, message.

The shared API credential is reversibly encoded in ze0.a; it is not reproduced in this report. No requests were sent manually to license or trial endpoints. The license HTTP client uses 15-second connection/read timeouts and certificate pinning for aacarplayvideo.com.

hm1 checks the installed signing certificate. isLicensed combines signing validation with purchase ownership, a valid cached key or an active trial; hasFullLicense excludes trials. Key cache validation checks expires_at and integer elapsed days <= 7, reduced to <= 1 when clock rollback is detected. Trial cache validity uses an elapsed-hours < 2 condition; trialRemainingMs additionally uses server remaining time or a 24-hour fallback from trial_start_time. The separate network exception fallback in gm1 returns a cached positive result without applying the same age calculation inside that method. These are branch descriptions, not proof of an externally exploitable bypass.

GET https://aacarplayvideo.com/client-versions.json supplies optional ios, android_vr and mweb version strings, validated by a regex before persistence. Server-side license state, fraud controls and remote response correctness cannot be derived from these APKs.

SECURITY-RELEVANT OBSERVATIONS AND ENGINEERING DEFECTS
======================================================
These are static review observations; no exploit or live backend test was performed.

1. The FreeTube WebView enables JavaScript, universal file-origin access and file-to-file access while exposing a powerful native bridge. The local-file URI resolver lacks visible normalization/containment checks. Exploitability requires a reachable untrusted-script/frame path and has not been established. c41's navigation interception is a relevant mitigation.
2. network_security_config permits cleartext globally. IP geolocation explicitly uses HTTP; user-provided IPTV/radio sources may also do so. Narrow per-domain policy would make the intended exposure clearer.
3. License and billing preference initialization has a plain SharedPreferences fallback; the backup resources do not exclude these files or the ordinary Room database. Actual backup recoverability depends on OS/key handling and was not tested.
4. The client contains a reversible shared API credential. Such a value cannot provide a strong confidential server-authentication boundary once distributed inside an APK. The server's additional checks are unknown.
5. web.readable.js around lines 45315–45405 shows a file-write error handler referencing a block-scoped variable before its declaration. Exact-function controlled replay confirmed a ReferenceError on a mocked write failure. cb() writes data-location.json with uri while lb() reads directory; controlled replay confirmed an undefined directory URI after reload, while the directory-key control passed. These are confirmed isolated JavaScript defects, not installed Android device reproductions.
6. isAppPaused returns false, so callers cannot use it to distinguish paused app state. Whether this affects playback depends on the event path.
7. Native source output has obfuscation and type-inference artifacts, including implausible casts. A JADX warning or pseudocode oddity alone is not classified as an app defect. Use Smali for exact branch/type behavior.

Evidence anchors: e41, a41, ag0, c41, ul, h92, ze0; network_security_config.xml; backup_rules.xml; data_extraction_rules.xml; web.readable.js.

RECONSTRUCTION BLUEPRINT
========================
A rebuild should preserve the three layers independently: shared native dashboard/controller; Android Auto/media-session adapters; FreeTube web app plus its Android bridge.

Data compatibility: recreate Room v13 using the recovered DDL and independently review its migration objects; preserve separate FreeTube NeDB files and document-tree mappings. Use named repository/model types corresponding to semantic-class-map.csv rather than copying obfuscated identifiers into new code.

Behavioral contracts: keep media-source selection, subtitle merging, seek restoration, module IDs/order, JS promise/event completion and error semantics explicit. License/purchase validation must be implemented against authorized publisher/account APIs, not simulated as always valid. Treat external video, IPTV, radio and Stremio APIs as replaceable adapters with controlled fixtures.

Verification matrix: startup and permission denial; each of the 19 module entries; local media formats; native and web YouTube playback; stream extraction failure paths; HLS/DASH/progressive selection; subtitle and background playback; file import/export and directory relocation; process restart/data migration; car connect/disconnect; mirror permission/gesture cleanup; valid/expired/offline licensing through authorized test accounts; billing cancellation/pending/acknowledgement; optional-module install/failure and missing module cases.

No buildable replacement project is claimed. Decompiled Java, raw Smali and formatted JS are evidence and recovery material, not original source or a demonstrated successful rebuild.
